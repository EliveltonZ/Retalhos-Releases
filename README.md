# Retalhos — instaladores

Este repositório guarda apenas os **instaladores** do Retalhos, publicados como *Releases*.
O código-fonte fica em um repositório privado.

O Retalhos procura aqui a versão mais nova (`versao.json` da última Release) e oferece a atualização
ao usuário. Para instalar manualmente, baixe o `Retalhos_Setup_<versão>.exe` da Release mais recente.
